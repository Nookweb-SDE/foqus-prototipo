# FOQUS · protótipo de interface

Build estático do protótipo do portal da FOQUS (gestão de desempenho e pesquisa de clima), publicado pela NookWeb para avaliação.
Dados fictícios, sem backend: o que você faz fica guardado só neste navegador. "Restaurar dados de exemplo", no menu da conta, volta ao começo.

Acesso: https://nookweb-sde.github.io/foqus-prototipo/

Na tela de entrada escolha um perfil (Colaborador, Gestor, RH, Admin Empresa, Consultor FOQUS ou Admin FOQUS).
"Começar do zero com tutorial" entra como um colaborador de exemplo, com a autoavaliação pendente e o tour guiado
aberto, e "Começar do zero como Admin FOQUS" entra na carteira de exemplo, com o tour guiado aberto em Empresas.

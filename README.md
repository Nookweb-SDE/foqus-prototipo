# FOQUS · protótipo de interface

Build estático do protótipo do portal de gestão de desempenho da FOQUS, publicado pela NookWeb para avaliação.
Dados fictícios, sem backend: tudo o que você faz fica só no seu navegador e some ao recarregar.

Acesso: https://nookweb-sde.github.io/foqus-prototipo/

Na tela de entrada escolha um perfil (Colaborador, Gestor, RH, Admin Empresa ou FOQUS). O botão
"Começar do zero com tutorial" entra como a colaboradora de exemplo com o passo a passo aberto.
